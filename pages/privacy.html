Privacy & Data Handling

My PunctuOwlity project includes an Android application and a separate static browser demonstration. They have different capabilities and storage mechanisms.

Browser demonstration

The browser demo stores account details, password-verification material, event details, and preferences in browser storage on the device. Browser accounts are not server-verified and browser storage is not a secure vault. Do not enter real passwords or sensitive personal information. Clearing site data may remove records; anyone with access to the browser profile or developer tools may be able to inspect or alter stored data.

Android application

The Android app stores account and event information in its app-local SQLite database. It can request SMS permission and, when the user enables reminders, send SMS messages using the device. Standard SMS and mobile-carrier handling may apply. The Android app also uses local notifications and scheduled alarms. Permission and settings can be changed in Android settings and within the app where available.

Third-party resources

Browser pages request fonts from Google Fonts, subject to network availability and the font provider’s own data-handling practices. The static demo does not require a project-operated backend to store browser accounts.

Managing information

Browser records can be removed through the application where supported or by clearing the site’s browser storage. Removing the Android app normally removes app-local data, subject to device and backup behavior. Do not assume deletion can reverse an SMS already sent.

Scope of this notice

This notice describes behavior visible in the supplied source project; it does not claim that a public service is operating, that no third party ever receives network metadata, or that data is encrypted beyond the platform’s protections.
